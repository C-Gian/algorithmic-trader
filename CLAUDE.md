# Ingresso per Claude Code

1. Leggi [AGENTS.md](AGENTS.md), [current_task.md](current_task.md) e [STATE.md](STATE.md).
2. Per il contesto di prodotto usa [PRODUCT-CONTEXT.md](docs/functional/PRODUCT-CONTEXT.md); approfondisci solo i riferimenti pertinenti al task.
3. Esegui soltanto un incarico READY o la prosecuzione autorizzata dello stesso incarico IN_PROGRESS. Con NONE, DRAFT o ACCEPTED non inventare il prossimo lavoro. Con BLOCKED non aggirare il blocco.
4. Implementa e risolvi i dettagli tecnici nel perimetro. Strategia, metodo e scelte numeriche essenziali spettano ad Astra/Director e, dove necessario, all'Owner.
5. Consegna risultati e verifiche effettive; non dichiarare la tua consegna accettata.

Non duplicare qui le istruzioni di AGENTS.md. La vecchia repository è un archivio, non una fonte automatica di regole applicabili.
